# MyFSL 發布說明（自己與家人安裝）

| 項目 | 內容 |
|---|---|
| 套件名稱 | `tw.myfsl.app`（除錯版為 `tw.myfsl.app.debug`，兩者可以同時裝在同一支手機） |
| 版本 | 1.0.0（versionCode 1） |
| 支援 | Android 8.0（API 26）以上 |
| 權限 | 無。App 不連網、不上傳資料 |
| 資料位置 | 只在手機裡（Room 資料庫＋設定）。Android 系統備份會一起帶走；App 內另有「匯出完整備份」 |

---

## 1. 第一次：建立簽署金鑰（只做一次）

```powershell
powershell -ExecutionPolicy Bypass -File tools\create-keystore.ps1
```

- 密碼由你自己輸入。會產生 `myfsl-release.jks` 和 `keystore.properties`，兩個都**不會**進 git。
- **一定要另外備份金鑰檔與密碼。** 遺失後新版本無法直接更新，只能解除安裝重裝（重裝前要先匯出完整備份，否則資料會不見）。

## 2. 產生安裝檔

```powershell
powershell -ExecutionPolicy Bypass -File tools\build-release.ps1
```

會依序執行：清除舊建置 → 全部單元測試 → lint → 壓縮混淆的正式版建置。全部通過才會輸出 `release-apk\MyFSL-1.0.0-1.apk`，並印出 SHA-256。

## 3. 安裝到手機

1. 把 APK 傳到手機（USB 複製到「下載」、或傳到自己的雲端硬碟）。
2. 在手機用「檔案」App 點開 APK。第一次會要求允許「安裝不明應用程式」，只對你用來開檔的那個 App 允許即可。
3. 安裝後打開，第一次會看到歡迎頁：
   - **開始設定帳戶**：直接用自己的資料。
   - **先用示意資料看看**：虛構資料，熟悉之後到「設定 → 清除所有資料」再開始。
   - **我有備份檔，要還原**：換手機時用。

## 4. 發新版本

1. 在 App 裡「設定 → 匯出完整備份」。
2. `app/build.gradle.kts` 的 `versionCode` **+1**，`versionName` 改成新版號。
3. 若有改資料表：提高 `AppDatabase` 的 version，並在 `Migrations.kt` 加升級 SQL（`MigrationTest` 會檢查）。
4. 執行 `tools\build-release.ps1`，把新 APK 裝到手機上（會覆蓋更新、保留資料）。

## 5. 上線前在手機上的驗收清單

開發環境的模擬器無法啟動，下列項目**尚未在實機上看過**，第一次安裝時請逐項確認：

| # | 操作 | 預期 |
|---|---|---|
| 1 | 第一次打開 | 歡迎頁；圖示為綠底長條＋黃色水位線 |
| 2 | 開始設定帳戶 → 新增「薪轉」銀行、錢包、信用卡 | 儲存後出現在清單；信用卡的「進階（選填）」可收合 |
| 3 | 計畫 → 匯入 CSV（Excel 另存的檔） | 預覽顯示編碼、合計、錯誤列號；匯入後有項目與摘要 |
| 4 | 計畫 → 月份表格 | 可左右滑，本月欄有底色，合計列與摘要一致 |
| 5 | 點一個項目 → 改某列的支付方式 → 儲存 | 清單的色點與金額跟著變 |
| 6 | 記帳 → 刷卡 → 分期 12 期 → 記下 → 復原 | 記下有提示；復原後紀錄消失 |
| 7 | 記帳 → 看紀錄 → 點一筆 → 改金額 | 儲存後金額改變 |
| 8 | 本期 → 開始檢查 → 填錢包與銀行金額 → 完成 | 完成畫面列出寫入內容；帳戶餘額更新 |
| 9 | 試算 → 新增情境「貸款整合卡債」 | 圖上多一條線；比較表多一欄 |
| 10 | 設定 → 匯出完整備份 → 從備份還原 | 還原確認視窗數量正確；還原後資料一致 |
| 11 | 手機切成深色模式 | 文字清楚，沒有白底閃爍 |
| 12 | 關掉 App 再打開 | 資料都還在，不再出現歡迎頁 |
| 13 | 記帳畫面上方的「本月到期」→ 點停車費 → 改成刷卡、選卡 → 記下 | 清單少一項；紀錄標「每月固定」、付款方式是刷卡；按提示條「復原」會回到清單 |
| 14 | 在紀錄刪掉一筆到期記下的（例如貸款月繳），再看記帳畫面 | 回到「本月到期」（刪除確認視窗有說明）；貸款剩餘期數加回一期 |
| 14a | 有到期還沒記下的項目時做本週檢查 | 第一步列出它們；選「已付」後對帳的推算已包含，不會算成漏記 |
| 15 | 本週檢查 → 到期確認選「延到下月」；下個月再檢查 | 下個月出現「延期款」那一列；選已付後紀錄標「延期款」 |
| 16 | 刪掉一筆「到期確認」補記，再開始檢查 | 那一項重新出現在到期確認 |
| 17 | 記帳 → 退款 | 紀錄標「退款」、金額為負，項目花費減少 |
| 18 | 對帳補了漏記差額後，記同一項目同一支付方式的一筆 | 問是否取代漏記差額；選「是」後差額減少，餘額不重複扣 |
| 19 | 有記帳的項目 → 編輯 | 類型 chips 停用並說明原因 |
| 20 | 刷卡分期 12 期，等第一期出現在「本月到期」記下後，到紀錄刪掉那一期 | 只有那一期（本金＋手續費）回到本月到期；原始消費與分期還在 |
| 21 | 記下上個月到期的項目，付款日選「今天」 | 銀行餘額馬上扣掉；計畫進度仍算在上個月 |
| 22 | 在紀錄編輯一筆「循環利息」只改備註 | 可以存檔 |
| 23 | 從備份還原進行中強制關閉 App，再打開 | 先出現「正在檢查資料…」，這時不能操作；接著提示「上次從備份還原沒有完成，已經放回還原前的資料」，帳戶、記帳與設定都是還原前的樣子 |
| 24 | 從備份還原進行中按返回鍵、點畫面 | 全畫面顯示「正在從備份還原…」，返回鍵與點擊都沒反應，底部導覽隱藏；完成後回到原畫面 |
| 25 | 在「帳戶」打開某個帳戶的編輯視窗不存，另一個畫面從備份還原（帳戶 id 相同、名稱不同），回來按儲存；再到「紀錄」對還原前就開著的一筆按刪除 | 都跳出「資料剛從備份還原或清除過…請重新確認後再操作」，還原後的帳戶與紀錄完全沒變；關掉重開編輯視窗後可以正常儲存 |
| 26 | 帳戶 → 信用卡「進階」打開依帳單繳款，填結帳日、截止日，選全額；另一張選最低並填利率與預估繳款 | 儲存後卡片顯示繳款方式、本期帳單還要繳多少與截止日；全額的卡不用填利率 |
| 27 | 截止日前 7 天、3 天（或在設定把提醒天數改成明天的天數）早上 | 手機收到「繳 X 還有 N 天截止」通知；已經在本月到期記下的不再通知 |
| 28 | 結帳日隔天早上點「帳單已結帳」通知 | 打開帳戶頁的帳單視窗，App 估計金額可以改成帳單金額；儲存後紀錄出現一筆「帳單差額」，本月到期的全額建議金額變成帳單金額 |
| 29 | 本月到期點繳卡費，把繳款方式從全額換成最低 | 金額變成最低（或預估）金額，記下後備註寫「（最低）」；下一期回到卡片預設的全額 |
| 30 | 本期頁與帳戶頁的可動用現金 | 旁邊寫「其中 $X 要留著繳卡費，扣掉後可用 $Y」；全額的卡算整筆欠款 |

有任何畫面怪怪的或閃退：到「設定 → 關於」看「上次當機紀錄」，按「複製紀錄」貼給開發者。

## 6. 已知限制

- 畫面沒有自動化測試（需要下載 Robolectric／Compose 測試套件，尚未加入）。
- 資料庫實際讀寫、備份還原交易、到期記下的寫入、刪除記帳的連動、降版保護沒有自動測試，只有程式碼審閱與上面的手動驗收。
- 到期的款項不會自動記，要在「本月到期」點下；沒點的會在本週檢查再列出。
- 相依套件不是最新版（lint 提示有新版）；升級需要下載，且要重新驗證。
- 一次只記錄最後一次當機。
